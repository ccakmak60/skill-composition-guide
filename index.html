SECTION 01 - THE IDEA

      
The skill graph idea

      

        One of most valuable ideas in agent work: encode knowledge + process into markdown skill,
        with optional scripts model can run repeatably. Skill graphs get intuitive fast: link
        dependent skills like Obsidian notes, then compose larger job functions out of smaller parts.
      

      

        But deep, dense dependency graphs become non-deterministic in practice. Skill A can reliably
        call Skill B, but past certain depth agents may skip calls, branch unexpectedly, or loop.
        Composition still matters, we just need a different structure.

SECTION 02 - THE PRIMITIVES

      
Atoms - capabilities

      

        Atoms are single-purpose building blocks. Keep scope narrow, contract clear, and behavior
        reliable enough to feel almost deterministic. Atoms usually should not call other skills.

SECTION 03 - THE CHAINS

      
Molecules - composites

      

        Molecules solve scoped problems by orchestrating 2-10 atoms. Push composition into
        the molecule itself with explicit steps or explicit routing rules, so runtime judgement
        stays bounded and reliable.
      

      

        Typical structures: (1) deterministic chain workflow, or (2) small orchestrator that knows
        limited atom set and composes them based on prompt. In both cases, stay explicit.

SECTION 04 - THE PLAYBOOKS

      
Compounds - playbooks

      

        Compounds orchestrate multiple molecules and hand agent meaningful autonomy.
        This level is naturally less deterministic because there are many judgement points,
        so human still drives intent, priorities, and approval gates.

Where skill graphs break

      

        Dense graphs add uncertainty: deeper chains, ambiguous routing, and circular dependencies.
        Use this as quick diagnostic before deciding where to add structure.
      

      

        
        
        
        
      

      

        
      

    


    
    

      
Leverage & brain RAM

      

        Brain RAM is bottleneck. If you can context-switch across five agents, running atom-level
        work consumes same slots as compound-level work, but delivers radically different output.

DRIVING COMPOUNDS

          
500 atomic units

          
1 compound orchestrates ~10 molecules. Judgement shifts up to strategic control.

        

      


      

        Working rule: compounds spanning more than 8-10 molecules start hitting reliability ceilings.
        Library naming that works well in practice: capabilities (atoms), composites (molecules),
        and playbooks (compounds). Biggest challenge remains consistency and testing time at every layer.
